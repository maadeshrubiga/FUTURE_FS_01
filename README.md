## Welcome to The Friendly Profile Portfolio

This is a professional portfolio website developed using the **Lovable AI** platform.

## Project Overview

This project is a comprehensive portfolio website featuring:
- **Hero Section** - Introduction and welcome message
- **About Section** - Personal background and information
- **Skills Section** - Technical skills and expertise
- **Projects Section** - Showcase of completed projects
- **Contact Section** - Contact information and form
- **Chat Modal** - Interactive chat functionality
- **Navigation** - Responsive navbar with smooth navigation

## Technologies Used

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## How to Run the Project

To start the development server, use the following command:

```sh
cd FUTURE_FS_01 && npm run dev
```
